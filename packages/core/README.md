# zomboid-models

Browser renderer for Project Zomboid (Build 42) characters, built on three.js. It draws a body with the clothing, hair, held items, and blood or wound decals described by a JSON document, and plays the game's own animations.

The package is in early development and is not published yet. See the [repository README](https://github.com/kentucky-vibes/zomboid-models#readme) for the project overview and the `docs/` folder for the JSON format and the integration guide.

This package contains no game assets. It loads assets produced by `zomboid-models-pipeline` from a URL that you host.

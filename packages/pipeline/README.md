# zomboid-models-pipeline

Command line tool that reads a Project Zomboid (Build 42) install, either the game client or the dedicated server, plus any number of mod folders, and writes the meshes, textures, animations, and catalog that the `zomboid-models` renderer loads in the browser.

The package is in early development and is not published yet.

The output folder is meant to be served as static files. It contains converted copies of game and mod assets, so hosting it publicly is subject to The Indie Stone's Terms and Conditions and to the permissions of the mod authors involved. The tool itself ships no assets.
